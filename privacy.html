Privacy Policy

This page explains what the TwoDay Studio website currently does with technical and contact information.

Website Analytics

The site loads Google Analytics 4 (GA4). GA4 receives page and interaction information through Google's analytics script and may use its own cookies or browser identifiers.

The site also sends analytics events to a TwoDay Studio endpoint hosted on Cloudflare Workers. These events include a randomly generated browser visitor ID, unique site visits, game identifiers, game launches and active session duration. When configured, the Worker also forwards game-session events to GA4.

Device Deduplication

The Cloudflare Worker reads the IP address and user-agent provided with a request, combines them and creates a SHA-256 hash. The application stores that hash in Cloudflare D1 to reduce duplicate visitor and play counts. The application code does not store the raw IP address or raw user-agent in D1, although Cloudflare processes request information to provide the Worker service.

Browser Storage and Cookies

The site uses browser storage for these purposes:

  • tds_vid, tds_visited and tds_plays support persistent analytics identification and deduplication.
  • twoday-theme and twoday-lang remember display preferences.
  • The browser game can use IndexedDB for local game files or save data.
  • Google Translate uses the googtrans cookie when a visitor selects a language.
  • Google Analytics may set analytics cookies when its script runs.

The website code does not use sessionStorage.

Translation and Country Lookup

Google Translate is loaded on supported pages when translation controls are available. On a first visit without a saved language preference, the site requests a country code from GeoJS to choose a default language. GeoJS receives the network information needed to answer that request, including the visitor's IP address.

Public Live Stats

The Live Stats page displays aggregate totals returned by the Cloudflare Worker, such as visitor counts, game launches, total active playtime and streak summaries. It does not display individual visitor IDs or individual device hashes.

Contact and Support

The current business and support forms do not submit to a TwoDay Studio web database. They prepare a message and open the visitor's email application. Information is sent only after the visitor sends that email. The message can include a name, email address, company, topic, game, device and message text.

Data Retention and Choices

The repository does not define an automatic deletion schedule for analytics records in Cloudflare D1. Visitors can clear site storage and cookies through their browser, block analytics scripts with browser controls or contact TwoDay Studio with a privacy question. Clearing local browser storage does not remove records already stored by analytics providers.

Third-Party Services

The site currently integrates Google Analytics, Google Translate, GeoJS, Cloudflare Workers and Cloudflare D1. Links to LinkedIn and other external platforms are governed by those services' own privacy practices.

Contact

For privacy questions, email contact@twodaystudio.com.
